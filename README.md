# 浅濑阅读器 Asase Reader

**Windows 上的本地离线漫画阅读器。** 把图片整理成「书架 → 作品 → 章节」，
用一个为看漫画调过的阅读器离线读：单图 / 连续滚动、长图、全屏、放大看细节、
深色模式、自定义封面与标签。所有数据都在你自己的磁盘上，不需要账号，也不上传任何内容。

书库内容可以来自本地图片、本地视频，也可以来自 B 站专栏（opus）。

当前版本 **2.1.0**（[更新日志](CHANGELOG.md)） · Windows 10/11 x64 · Python 3.11+（源码运行）

> **使用边界**：仅用于个人离线阅读，请遵守站点条款与版权，**不要二次分发下载到的内容**。
> 本仓库公开的是代码，不含任何书库、下载内容或账号凭据；程序默认不使用登录 Cookie，
> 仅在遇到付费墙时由用户临时提供、只存内存、退出即消失；视频转图集需自备 ffmpeg。
> 采用 MIT 许可（Copyright (c) 2026 浅濑凛 (Asase Rin)）。**未做代码签名**，
> 从网络下载的安装包会触发 Windows SmartScreen「未知发布者」，
> 核对 Release 附带的 SHA256 后选择「更多信息 → 仍要运行」。

## 阅读器

| | |
|---|---|
| 书架 | 作品 → 章节两级；标签与作者筛选、关键词搜索、分页；按最近更新 / 最近阅读排序，可自定义封面 |
| 阅读 | 单图（滚轮 / ←→ / A D 翻页，单击进出全屏）与连续滚动两种模式；长图按宽铺满、先滚完再翻页；缩略图带、章末提示下一章 |
| 看细节 | Ctrl+滚轮 / `+` `-` 放大，拖动平移，`0` 复位；换页自动复位 |
| 界面 | 三套风格、浅色 / 深色、封面形状三档、卡片大小四档；无边框窗口与原生最大化动画；偏好自动保存 |
| 整理 | 作品名 / 作者 / 章节名 / 注释、章节排序、删除多余图片（删完自动重新编号） |
| 导出 | 把作品 / 章节 / 整个书库复制成普通文件夹（含 `work.json` 与封面），不改原件 |

## 内容从哪来

- **本地导入**：一组图片或一个文件夹 → 一个章节；也支持把本地视频原样作为一个章节播放。
- **视频转图集**：按场景变化抽帧（需自备 ffmpeg，不内置、不联网），原视频一个都不删。
- **B 站专栏（opus）**：粘贴专栏链接或导入 URL 列表，把图片下载到本地入库，供离线阅读。
  只抓图片，正文文字不解析、不存储。**仅限个人使用**，见下方风控红线。

新章节先进入「未入库」，再归类到作品 —— 三种来源共用同一套章节结构。

## 运行

两种交付形态，任选其一（见 [Releases](https://github.com/tiger-forest/AsaseReader/releases)）：

| 形态 | 怎么用 | 装到哪 |
|---|---|---|
| 安装包 `AsaseReaderSetup-<ver>.exe` | 双击安装，简体中文向导、免管理员；开始菜单 / 桌面快捷方式 / 卸载项 | 默认 `%LOCALAPPDATA%\Programs\AsaseReader`，可改路径 |
| 绿色版 `AsaseReader-<ver>-portable.exe` | 双击即用，可拷走 | 不安装 |

- **首次启动**会先让你确认书库目录（不可跳过，已预填默认值），确认后才进入书架。
- 书库默认在「文档」`\AsaseReaderLibrary`；配置与界面偏好固定放在 `%LOCALAPPDATA%\AsaseReader\`。
  **卸载只删除程序本体，书库与配置一律保留。**
- **不要同时开安装版和绿色版**：两者共用固定端口 28765 与 WebView2 数据目录。
- 界面依赖 WebView2 运行时（Win10/11 一般自带）；缺失时安装器会引导下载微软官方在线安装器，
  下载失败不阻断安装。

源码运行：

```bash
pip install -e .
python -m asase_reader --gui       # 图形界面
python -m asase_reader --version
```

## 从源码构建

```bash
python tools/build_release.py --check    # 只体检，不写文件
python tools/build_release.py --build   # 自检 → 两轨打包 → 安装包 → SHA256
```

`--build` 在 `dist/release/` 产出安装包、绿色单文件版、`SHA256SUMS.txt` 与
`BUILD_INFO.txt`，并校验三件产物的时间都晚于源码。编安装包需要 **Inno Setup 6**
（脚本会自动定位，也可用 `ASASE_ISCC` 指定）；只出绿色版可单跑
`pyinstaller AsaseReader.spec --noconfirm --clean`。

发版时**只改 `src/asase_reader/__init__.py` 的 `__version__` 一行**，改完必须重跑
`--build`：版本资源、安装包名、exe 内版本都由它派生。

`tests/fixtures/` 里的专栏页面仅用于解析测试，图片是合成占位文件。
完整变更记录见 [CHANGELOG.md](CHANGELOG.md)。

## 风控红线（改动下载相关代码时不要触碰）

并发上限 2、页面间隔随机 2–5 秒、每日总量上限、相同 URL 只下载一次、
遇 HTTP 412 指数退避且连续触发即停、不轮换 IP / 代理、不二次分发下载内容。
登录 Cookie **只存内存**、只用于抓取专栏页面那一次请求，图片下载一律不带凭据，
也不保存响应返回的新 Cookie。
